# Vibe Coding 高效能秘籍

> 来源：拼好课《Vibe Coding 高效能秘籍》（[课程入口](https://pin-haoke.cc/courses/cms2m4fdt0002psp7kb2b6999)），作者做过大厂一句话生成应用平台 + AI 产品 Sitor。本组笔记是全 16 节课的提炼整理。

**全书一句话主线：跟 Agent 协作，本质是一门管理学。** 用上 Agent 那一刻起，你就不再是执行者，而是派活、给上下文、验收产出、把控方向的管理者。真正限制产出的从来不是模型智力，而是你调度、管理它的能力——所以出问题时，先检查自己的管理动作，再怀疑模型。

这组笔记按课程章节拆开：

1. 认知重建：一句话干活为什么是谎言，幻觉怎么工程化控制。
2. 上下文工程：CLAUDE.md 怎么写、会话上下文怎么管理。
3. 验收闭环：让机器替你把关代码与 UI 质量。
4. 需求规划与 UI 设计：决策是你的，执行交给 Agent。
5. 沉淀复利：从 Skill 到自动化工作流。
6. 升维：全自动化流水线与判断力。
7. 终极心法：四种认知状态。

## 先记住的五条

- **派活四件套**：目标、边界（哪些不能碰）、历史包袱（只有你知道的坑）、验收标准，缺一样 Agent 就只能猜。
- **幻觉不能消除，但能工程化衰减**：叠独立 review（干净上下文 / 换模型），90% → 99% → 99.9%。
- **上下文是预算不是仓库**：能写进文件的信息（CLAUDE.md / HANDOFF.md）不要指望它待在上下文里。
- **能被机器自动拦下的错误，就不该消耗你的注意力**：typecheck / lint / 测试 / hooks / 回归用例。
- **每次翻车都沉淀成一条规则**：错题本是全书性价比最高的机制，翻车积攒的是资产不是损失。
