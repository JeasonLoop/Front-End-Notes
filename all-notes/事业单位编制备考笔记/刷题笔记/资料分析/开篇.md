## 一、五年规划

全称为中华人民共和国国民经济和社会发展五年规划纲要，是中国国民经济计划的重要部分，属长期计划。主要是对国家重大建设项目、生产力分布和国民经济重要比例关系等作出规划，为国民经济发展远景规定目标和方向。中国从1953年开始制定第一个“五年计划”。从“十一五”起，“五年计划”改为“五年规划”。

（1）十一五：2006年~2010年

（2）十二五：2011年~2015年

#### （3）十三五2016年~2020年(重点)

（4）十四五：2021年~2025年

## 二、基期量与现期量

### 1、现期

我们所要研究的、用来和基期进行对比的那个时期。也就是“当前”的、我们更关心的时期。：①分析公司2024年的销售额增长率，2024年就是现期。②2023年比2021年收入增长了10%。这里 2023年就是现期。

### 2、现期量

在现期这个时间点上的具体数值。通常用符号 A 表示。
公式：
现期量 = 基期量 + 增长量 = 基期量 × (1 + 增长率)
例：2024年的销售额是1200万元，2023年（基期）的销售额是1000万元，分析2024年的销售额增长率。那么2024年是现期，1200万元就是现期量。

### 3、基期

作为对比参照物的时期。比如像一把尺子的“0刻度”，你想要知道变化了多少，总得有个起点，这个起点就是基期。：①分析公司2024年的销售额增长，那么2023年通常会被选为基期。②2023年比2021年收入增长了10%。这里 2021年就是基期。

### 4、基期量

在基期这个特定时间点或时间段内的指标数值。通常用符号 B 表示。
公式：
基期量 = 现期量 - 增长量 = 现期量 / (1 + 增长率)
例：2024年的销售额是1200万元，2023年（基期）的销售额是1000万元，分析2024年的销售额增长率。那么2023年是基期，1000万元就是基期量。

## 三、增长量与增长率

### 1、增长量

就是在某个时间段内，现期量相对于基期量的绝对变化量。它表示实际增加了多少或减少了多少。这个变化量是通过现期量减去基期量来计算，
如果结果是正数，说明增加了；如果是负数，那就说明减少了

### 2、增长量公式

增长量 = 现期量 - 基期量 = 基期量 × 增长率 = 现期量 × 增长率 / (1 + 增长率)
例1：2024年的销售额是1200万元，2023年的销售额是1000万元。
销售额增长量 = 1200 - 1000 = 200万元（增长了200万元）。
例2：2024年的销售额增长率为-10%，2023年的销售额是1200万元。
销售额增长量 = 1200 ×（-10%）= -120万元（减少了120万元）。

### 3、增长率

现期量相对于基期量的相对变化程度，通常用百分比(%)表示。即在基期量的基础上增长了多大的幅度结果可正可负。正数表示增长率（如增长20%），负数表示下降率（如下降10%）。

（1）增长率又称增幅、增速、增长幅度、增长速度等。

（2）增长率一般用 r 字母代表（rate 的简写）

（3）“减少率或下降幅度”本质是一种未带负号的“增长率”

### 4、增长率公式

增长率 = (现期量 - 基期量) / 基期量 = 增长量 / 基期量

### 5、增长率读数比较

（1）增幅、增速、增长率比较的时候需要看正负号。

（2）变化幅度、涨跌幅比较的时候只需要看绝对值。

（3）降幅比较时，先保证是下降（负数），再看绝对值。

### 6、概念混淆

（1）问增长最多 -> 比较增长量。

（2）问增长最快 -> 比较增长率。

## 四、同比、环比

### 1、同比

同比是以上年同期为基期相比较，即本期某一时间段（点）与上年相同时间段（点）相比，
可以理解为今年第n月与去年第n月的比较：2025年1月的同比就是2024年1月。2025年的同比就是2024年。2025年第二季度的同比就是2024年第二季度。

### 2、环比

环比是与上一个相邻统计周期相比较，表明统计指标逐期的发展变化，
可以理解为第n月与第n-1月的比较：2025年1月的环比就是2024年12月。2025年的环比就是2024年。2025年第二季度的环比就是2025年第一季度。

## 六、人口相关

### 1、出生率

出生率 = 出生人口 / 平均人口数 × 1000‰

### 2、死亡率

死亡率 = 死亡人口 / 平均人口数 × 1000‰
平均人口数 = （年初人口数 + 年末人口数）÷2

### 3、自然增长人口

= 出生人口 - 死亡人口

### 4、自然增长率

= 出生率 - 死亡率

### 5、城镇化率

城镇化率 = 城镇人口 / 总人口 × 100%
