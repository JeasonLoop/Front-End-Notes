# 1. Python 与后端地基

> 前端对照：先把语言和 HTTP 补系统 · 跃迁：语言切换

专为前端转 Agent 设计的两周补课。第 1 周用 JS 心智对照 Python 语法与工程习惯；第 2 周补 HTTP、FastAPI、异步、SQL、密钥与 Docker。不求成为后端专家，但后面 RAG / Agent 不再卡在「看不懂报错」。

## 学习建议

每天写「JS 里我怎么写 → Python 里怎么写」。作业以小脚本和 curl 验收，不要只看视频。类型注解和 venv 从第一天就用，别等后面补。
