# Agent 驱动的自动化投研

周期：[[01-周计划/W8-项目二-投研-Agent-面试|W8]]

**场景**：输入公司名，自动搜集、分析财报、撰写研报。

**简历钩子**：复杂工作流自动化，量化分析师效率提升。

**技术栈**：`CrewAI / LangGraph` · `Search API` · `PDF 解析` · `重试与状态机`

## 验收

- [ ] 信息搜集 / 财报分析 / 报告撰写三角色
- [ ] 至少 5 个工具（搜索、SEC、文件读写等）
- [ ] 任务成功率 > 95%，有重试与降级
- [ ] 顺序工作流并落盘中间产物
