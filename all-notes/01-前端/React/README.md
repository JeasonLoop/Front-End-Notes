# React 教程

这是一个 React 学习教程集合，包含从基础到进阶的完整学习路径。

## 📚 目录

### 基础篇
1. [基础入门](./01-基础入门.md) - JSX、组件、Props、State、事件处理
2. [Hooks](./02-Hooks.md) - useState、useEffect、useContext、自定义 Hooks

### 进阶篇
3. [状态管理](./03-状态管理.md) - Context、Redux、Zustand、Jotai
4. [路由管理](./04-路由管理.md) - React Router 配置和使用

### 实战篇
5. [性能优化](./05-性能优化.md) - memo、useMemo、useCallback、代码分割
6. [最佳实践](./06-最佳实践.md) - 项目结构、代码规范、TypeScript

## 🚀 学习路径

1. **初学者**: 从基础入门 → Hooks → 状态管理基础
2. **进阶者**: 路由管理 → 状态管理进阶 → 性能优化
3. **实战者**: 最佳实践 → 项目实战 → 架构设计
