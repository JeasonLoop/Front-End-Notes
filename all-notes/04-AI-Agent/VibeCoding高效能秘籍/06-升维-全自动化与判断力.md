# 升维：全自动化与判断力

> 对应课程第六章。全自动流水线怎么搭才敢放手，以及人在这个时代最值钱的能力。

## 1. 凭什么放心让它自己跑

半自动时代人在场干两件事：唤起任务（纯体力活，放心交出去）+ 顺手把关。把"顺手把关"拆开看——查重复联系、验证额度没重复发、核对引用的学习内容真实存在——**这些检查没有一条真的需要"人"，需要的只是有人把它们写下来**。全自动第一步：把人顺手做的检查翻译成机器能执行的检查。

翻译不出来的才留人：语气配不配品牌气质这类判断；以及**权限问题**——发邮件、push 代码、发新版本、涉及金钱的操作，拍板权本来就该在人手里，这是流程设计不是自动化不足。

升级判据：**错题本扎实了没有**。靠人脑记教训的流程没资格全自动；教训基本变成机器检查了，人 check 就没意义。

## 2. 三档触发架构

| 档 | 机制 | 工具 |
| --- | --- | --- |
| 时间驱动 | 到点就跑 | Claude Code `/loop 1h 检查后端健康状态`（单会话最多 50 个任务、循环 7 天自动过期防烧 token） |
| 事件驱动 | 有事才跑，不做无意义轮询 | hooks（最小形态）、webhook + 无头模式（`claude -p "..." --dangerously-skip-permissions` / `codex exec`）、GitHub Actions 版 |
| 目标驱动 | 只给目标，Agent 自己定节奏 | `/goal`（定义机器可判定的终态）+ `/loop` 动态模式。最不成熟：目标越模糊，验证器就得越厚 |

注意区分：`/loop` 是同一提示词按节奏反复跑（监控/例行）；后台 Agent 是一次性异步任务。事件驱动需要一台常驻环境接 webhook。

## 3. 流水线四部件

一条能让你在旁边安稳睡觉的全自动流水线 = **触发器 + 执行体 + 验证器 + 通知器**。

以每日增长日报为例：

- 触发器：每天 09:00。
- 执行体：/user-growth-daily Skill，查注册数、留存、DAU、有效新用户。
- 验证器：各渠道注册数之和 = 总数；日期不能错位；SQL 空结果要报警不许发全零报告。
- 通知器：摘要推飞书群（群机器人 webhook 直接给 Agent）。**正常时给摘要，异常时才 @ 人。**

win-back 全自动版：验证器三连（不在已联系表、按 source_id 去重、引用记录真实存在）→ 有对象时把"联系谁、为什么、邮件写了什么"推群等确认放行。

## 4. 出错谁兜底

- **降级**：验证器拦下问题不硬着头皮往下走，退回半自动（产出保留、发送暂停、等人审）。
- **告警**：**比执行报错更可怕的是静默失败**——失败必须出声，宁可多吵一次，不能让系统安静地挂掉。
- **幂等**：重跑不产生副作用（已联系表就是幂等设计，重跑不会骚扰第二遍）。

人的位置：执行者 → 管理者 → **系统设计者**。退场的只是执行；规则永远是人定的——验证器查哪几条、什么算异常、哪个流程够格全自动，这些判断系统沉淀不了。

## 5. 判断力怎么练

AI 把"做出来"的成本打到接近零，稀缺的只剩两个判断：**做什么，以及做到什么程度算好**。"初级岗位完蛋了"是误导——变的是爬梯子的方式：以前反馈靠踩坑（一年几次技术选型？），现在一天几十次交互、每次都是你的判断 vs 模型输出的对照实验。反馈密度极高，但也**极易流走**——AI 把坑替你填了，你若无其事过去，那次成长就没了。

核心两个字：**在场**。AI 干活时你的判断不能离场。三个动作点：

1. **出手前：先落下自己的锚点**。抛问题前花 1~2 分钟自己想一遍（有个模糊预判就够），防锚定效应。提问方式：不要问"怎么实现"，问"给我两三个方案，说清各自适用场景、代价和局限"——判断力在取舍之间练出来。
2. **拿到产出时：反着问，比着看**。追问"这个方案什么情况下会失败？""你漏掉了什么？"——问几十次后这些视角会内化。对比训练：让 AI 出两版，用具体语言说出哪版为什么好；说不出来说明还没真懂，也意味着你可能正在不知不觉生产 AI Slop。
3. **翻车后：错题本是判断力的外挂**。把错误写成规则的过程（本质是什么？什么条件复现？边界在哪？）就是判断力的训练——写给 Agent 的每条规则也存进了你自己的判断系统。

场外功：**审美是喂出来的**。critique 报告连看十几份，问题自己会跳出来；多读好源码、高手决策复盘，看时多问一层"它为什么好"，看懂就借来用。书法要临帖，模仿就是品味在长的样子。

**在场也要分级**：日常小改动直接放行；三类任务上全套——技术选型、对外产出（发出去收不回来的）、心里咯噔一下的东西（说不清哪儿不对恰恰是该补课的地方）。

判断力的复利会顺着系统层层放大：判断准 → review 质量高 → 规则质量高 → Agent 产出基线高 → 敢全自动的流程多。模型换代、工具淘汰，只有判断力搬到哪套工具上都跟着你。

## Checklist

- [ ] 全自动之前，错题本里的教训已基本变成机器检查
- [ ] 高权限操作（发送、push、金钱）留了人工确认节点
- [ ] 有降级、告警、幂等三件套，不存在静默失败
- [ ] 关键决策前先有自己的预判，不直接吃 AI 的第一个答案
- [ ] 翻车后写过规则，而不只是修完就算了
